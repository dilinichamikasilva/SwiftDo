# 🚀 Swift Do - Task Management System

A high-performance, modern **Task Management Dashboard** built using the **MEAN** stack (with an **Angular** frontend). This application features an attractive, high-contrast UI and a robust backend to handle task lifecycles, real-time status updates, and datetime scheduling.

---

## ✨ Key Features

* **Smart Task Scheduling:** Integrated `datetime-local` support to capture both date and time for every mission.
* **Three-Stage Lifecycle:** Dedicated states for **To Do**, **Ongoing** (In-Progress), and **Done**.
* **Dynamic Filtering:** Instant view switching between all tasks, active items, or completed goals.
* **Modern UI/UX:** High-contrast Indigo theme with geometric backgrounds, hover effects, and responsive design.
* **Full CRUD:** Create, Read, Update, and Delete operations synced with a MongoDB database.
* **Real-time Toasts:** Instant visual feedback for successful updates or error handling.

---

## 🛠️ Technical Stack

### Frontend
* **Framework:** Angular 17+ (Standalone Components)
* **Styling:** Custom CSS3 with Variable-driven Theming
* **State Management:** RxJS Observables
* **Validation:** Reactive forms/ngModel patterns

### Backend
* **Runtime:** Node.js
* **Server Framework:** Express.js
* **Database:** MongoDB via Mongoose ODM
* **API Pattern:** RESTful Architecture
